# 涂抹工具使用指南

## 功能概述

涂抹工具是一个强大的图像编辑工具，允许用户通过手绘笔刷来擦除或保留图像的特定区域。

## 功能特性

### 1. 可调节笔刷大小
- **范围**: 5-100 像素
- **实时预览**: 光标会显示当前笔刷大小
- **精确控制**: 使用滑块精确调整

### 2. 两种擦除模式

#### 擦除模式 (Erase)
- **功能**: 擦除涂抹区域的像素
- **效果**: `destination-out` 合成模式
- **用途**: 移除不需要的图像部分

#### 反向擦除模式 (Inverse)
- **功能**: 保留涂抹区域，擦除其他部分
- **效果**: `destination-in` 合成模式
- **用途**: 快速提取需要的图像部分

### 3. 保存为蒙版
- **功能**: 将涂抹路径保存为独立的蒙版图层
- **用途**: 
  - 非破坏性编辑
  - 重复使用相同的选区
  - 后期调整蒙版效果

## 使用步骤

### 基本使用

```
1. 选中一张图片
2. 点击操作栏的 "涂抹" 按钮
3. 在图片上涂抹需要编辑的区域
4. 选择擦除模式
5. 点击 "应用" 或 "保存为蒙版"
```

### 详细步骤

#### 步骤 1: 选择图片
- 点击画布上的任意图片
- 确保图片被选中（显示蓝色边框）

#### 步骤 2: 进入涂抹模式
- 点击图片上方操作栏的 **"涂抹"** 按钮
- 屏幕顶部会出现涂抹工具控制栏

#### 步骤 3: 调整笔刷大小
```
笔刷大小: [====|=====] 20

- 拖动滑块调整大小
- 数字显示当前大小
- 光标会显示笔刷预览
```

#### 步骤 4: 选择擦除模式

**擦除模式**:
```
[ 擦除 ] [ 反向擦除 ]
```

- **擦除**: 点击 "擦除" 按钮（蓝色高亮）
- **反向擦除**: 点击 "反向擦除" 按钮（蓝色高亮）

#### 步骤 5: 在图片上涂抹

**涂抹操作**:
```
1. 按住鼠标左键
2. 在图片上拖动
3. 松开鼠标完成涂抹
```

**涂抹预览**:
- 蓝色路径显示涂抹区域
- 路径宽度等于笔刷大小

#### 步骤 6: 应用或保存

**选项 A: 应用擦除**
```
[ 应用 ]
```
- 根据选择的模式擦除图像
- 立即更新图片
- 操作不可逆

**选项 B: 保存为蒙版**
```
[ 保存为蒙版 ]
```
- 将涂抹路径保存为蒙版
- 不修改原图
- 可后续应用或调整

**选项 C: 重新涂抹**
```
[ 重画 ]
```
- 清除当前涂抹路径
- 重新开始涂抹

**选项 D: 取消**
```
[ 取消 ]
```
- 退出涂抹模式
- 不做任何修改

```javascript
  <svg xmlns="http://www.w3.org/2000/svg" width="${brushSize}" height="${brushSize}">
    <circle cx="${brushSize/2}" cy="${brushSize/2}" r="${brushSize/2}" 
            fill="none" stroke="black" stroke-width="1"/>
  </svg>
') ${brushSize/2} ${brushSize/2}, crosshair
```

### 路径绘制

```javascript
// SVG 路径
<path
  d="M x1 y1 L x2 y2 L x3 y3 ..."
  stroke="rgba(59,130,246,0.8)"
  strokeWidth={brushSize}
  strokeLinecap="round"
  strokeLinejoin="round"
/>
```

### 擦除算法

**擦除模式 (destination-out)**:
```javascript
resultCtx.globalCompositeOperation = 'destination-out';
resultCtx.drawImage(maskCanvas, 0, 0);
```
- 涂抹区域的像素被移除
- 其他区域保持不变

**反向擦除模式 (destination-in)**:
```javascript
resultCtx.globalCompositeOperation = 'destination-in';
resultCtx.drawImage(maskCanvas, 0, 0);
```
- 只保留涂抹区域的像素
- 其他区域被移除

### 蒙版存储

```javascript
const maskId = `mask-${Date.now()}`;
const updatedMasks = {

    ...masks[shapeId],
```

## 故障排除

### 问题 1: 涂抹按钮无响应

**原因**: 未选中图片  
**解决**: 先点击画布上的图片

### 问题 2: 涂抹路径不显示

**原因**: 笔刷大小过小或光标不在图片上  
**解决**: 
- 增大笔刷大小
- 确保在图片范围内涂抹

### 问题 3: 应用后效果不明显

**原因**: 笔刷大小不合适  
**解决**: 
- 擦除模式: 增大笔刷
- 反向擦除: 确保完全覆盖目标区域

### 问题 4: 保存的蒙版找不到

**原因**: 蒙版存储在图层系统中  
**解决**: 
- 查看右侧图层面板
- 查找对应图层的蒙版列表

## 最佳实践

### 1. 笔刷大小选择

```
小细节 (5-15):   修复小瑕疵、精确擦除
中等 (15-40):    常规编辑、轮廓涂抹
大面积 (40-100): 快速去背景、大区域填充
```

### 2. 模式选择

```
擦除模式:
  ✓ 去除水印、瑕疵
  ✓ 修复图像
  ✓ 局部删除

反向擦除模式:
  ✓ 提取主体
  ✓ 去除背景
  ✓ 创建剪影
```

### 3. 蒙版使用

```
保存为蒙版的场景:
  ✓ 需要多次应用相同选区
  ✓ 非破坏性编辑
  ✓ 复杂选区的保存
  ✓ 多图层使用相同蒙版
```

```
推荐流程:
1. 先用大笔刷快速涂抹大区域
2. 再用小笔刷精修边缘
3. 使用 "重画" 功能修正错误
4. 确认无误后点击 "应用"
```
