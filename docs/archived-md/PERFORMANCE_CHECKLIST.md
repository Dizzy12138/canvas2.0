#### 大量图层（>100 图层）
建议实现虚拟化滚动：
```javascript
import { FixedSizeList } from 'react-window';

// 虚拟化列表
<FixedSizeList
  height={600}
  itemCount={layers.length}
  itemSize={60}
  width="100%"
>
  {({ index, style }) => (
    <div style={style}>
      {renderLayer(layers[index])}
    </div>
  )}
</FixedSizeList>
```
